Privacy Policy

This Chrome extension does not collect, store, or transmit any personal or sensitive user data.

All data used by the extension (such as to-do items or settings) is stored locally on the user’s device using Chrome’s storage APIs and is never shared with third parties or external servers.

The extension does not use analytics, tracking, advertising, or external network requests.

If you have any questions or concerns about this privacy policy, you may contact the developer via the Chrome Web Store listing.
